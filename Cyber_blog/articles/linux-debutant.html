LINUX • 8 MIN DE LECTURE

10 commandes Linux pour débuter

La majorité des outils de cybersécurité tournent sous Linux. Avant de penser outils, il faut être à l'aise avec le terminal : voici les dix commandes indispensables pour commencer.

Avant de commencer

Ouvre un terminal. Le prompt se termine par $ pour un utilisateur normal et par # pour l'administrateur (root). Une commande se compose d'un nom, puis d'options (souvent précédées de -) et d'arguments.

1. pwd — où suis-je ?

Affiche le répertoire courant, ton point de repère dans l'arborescence.

pwd

2. ls — lister le contenu

Liste les fichiers du répertoire courant.

ls -la
ls -lh /var/log

-l affiche le détail (permissions, propriétaire, taille), -a inclut les fichiers cachés et -h rend les tailles lisibles.

3. cd — se déplacer

cd /etc
cd ..
cd ~

.. remonte d'un niveau, ~ va dans ton dossier personnel et cd seul fait pareil.

4. cat — lire un fichier

cat /etc/hostname

Affiche le contenu d'un fichier texte dans le terminal. Pour les longs fichiers, préfère less.

5. grep — rechercher du texte

grep "root" /etc/passwd
grep -r "password" /etc

grep filtre les lignes contenant un motif, et -r parcourt les dossiers récursivement. C'est l'outil indispensable pour analyser des logs.

6. find — localiser des fichiers

find / -name "*.conf" 2>/dev/null

Recherche par nom, par taille ou par date. Très utile en forensic pour retrouver un fichier modifié récemment.

7. chmod — gérer les permissions

chmod 644 rapport.txt
chmod 755 script.sh

Trois droits : r (lecture), w (écriture), x (exécution), répartis entre propriétaire, groupe et autres. 644 et 755 sont les valeurs les plus courantes.

8. ps — voir les processus

ps aux
ps aux | grep ssh

Liste les programmes en cours d'exécution. Combiné à grep, il permet d'isoler un service précis.

9. sudo — élever ses privilèges

sudo apt update

Exécute une commande avec les droits d'administrateur. À utiliser avec parcimonie : une commande destructrice lancée avec sudo ne peut pas être annulée.

10. man — lire la documentation

man nmap

Affiche le manuel d'une commande. Apprendre à lire man rend autonome : presque toutes les réponses y sont déjà.

Astuce : la touche Tab complète automatiquement les noms de fichiers, et la flèche du haut rappelle la commande précédente. Ces deux réflexes font gagner beaucoup de temps.
⚠ Attention : la commande rm -rf supprime définitivement des fichiers, sans confirmation ni corbeille. Vérifie toujours deux fois le chemin avant de valider.

À retenir

  • Dix commandes couvrent la majorité des besoins quotidiens.
  • man et --help sont tes meilleurs alliés.
  • Les permissions (chmod) sont au cœur de la sécurité Linux.
