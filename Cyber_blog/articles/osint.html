OSINT • 7 MIN DE LECTURE

Introduction à l'OSINT

Avant d'attaquer une machine, on attaque l'information. L'OSINT consiste à rassembler des données publiques pour comprendre une cible. Bien utilisée, c'est surtout une méthode pour mesurer sa propre exposition.

Qu'est-ce que l'OSINT ?

L'OSINT (Open Source Intelligence) désigne la collecte d'informations à partir de sources publiques et légales : sites web, registres officiels, réseaux sociaux, moteurs de recherche, données ouvertes. Ce n'est pas de l'espionnage : tout ce qui est collecté était déjà accessible à tous.

En cybersécurité, l'OSINT sert à connaître sa propre exposition — la surface d'attaque externe — pour mieux la réduire.

Le cycle du renseignement

  1. Cadrer : quelle question veut-on résoudre ?
  2. Collecter : rassembler les sources pertinentes.
  3. Traiter : nettoyer, dédoublonner, organiser.
  4. Analyser : recouper les informations entre elles.
  5. Diffuser : produire un rapport clair et actionnable.

Chaque étape compte. Une collecte massive sans analyse ne produit qu'une accumulation de données, pas du renseignement.

Les opérateurs de recherche

Les moteurs de recherche permettent des requêtes très précises pour retrouver des fichiers exposés accidentellement. 

site:example.com
filetype:pdf confidential
intitle:"index of"
  • site: limite la recherche à un domaine.
  • filetype: cible un format de fichier.
  • intitle: cherche dans le titre des pages.
Usage défensif : ces requêtes servent d'abord à vérifier qu'aucun document interne n'est indexé publiquement sur son propre domaine. C'est un contrôle simple à réaliser et souvent révélateur.

Les sources utiles

  • Registres officiels : WHOIS, DNS, bases de données d'entreprises.
  • Certificats TLS : ils révèlent les sous-domaines exposés.
  • Archives web : versions passées d'un site.
  • Réseaux sociaux : informations publiées volontairement par les salariés.
  • Bases de vulnérabilités : CVE, NVD, Exploit-DB.

Un exemple concret : cartographier ses sous-domaines

Une organisation publie souvent sans le savoir une liste de sous-domaines via les certificats TLS. La transparence des certificats (Certificate Transparency) rend cette information consultable par tous. 

crt.sh -> %.example.com

Résultat : une liste de sous-domaines, dont certains oubliés ou mal configurés. Pour l'attaquant, c'est une piste ; pour le défenseur, c'est une checklist de vérification.

⚠ Éthique et légalité : l'OSINT s'arrête là où commence l'intrusion. Ne pas contourner une authentification, ne pas harceler une personne, ne pas collecter de données personnelles sans base légale (RGPD). Collecter ne veut pas dire harceler.

OSINT offensif et OSINT défensif

Le pentesteur utilise l'OSINT en phase de reconnaissance pour identifier des cibles. Le défenseur utilise les mêmes techniques pour découvrir ce qui est déjà visible de l'extérieur. Les outils sont identiques, l'intention diffère : c'est l'autorisation qui fait la différence.

À retenir

  • L'OSINT exploite uniquement des sources publiques.
  • Le renseignement naît de l'analyse, pas de la collecte brute.
  • Les opérateurs de recherche révèlent des fuites involontaires.
  • La valeur principale de l'OSINT est défensive : connaître son exposition.
  • Respecter la vie privée et le RGPD n'est pas optionnel.
